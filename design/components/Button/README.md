# Button

A square-cut uppercase button with a hard `ink` border and `shadow-offset`; it drops to `shadow-press` when pressed.

- `primary` (`scarlet` with `on-scarlet` text) is for the one thing the page is for: "Get tickets", "Listen on Bandcamp". One per screen.
- `secondary` (`paper` with `ink` text) for everything else.
- Pass `href` to render a link that looks like a button; otherwise it renders a `<button>`.
- Labels are verbs, one to three words. Never tilt a button.
