# LineUp

The band line-up as flush, square-cut tiles: each member's role in `stamp` type above their name in `title` type.

- Pass `members` as `{ name, role }` in the order the band wants them read. The first tile is `scarlet` with `on-scarlet` text; the rest are `paper` with `ink` text.
- Tiles butt up against each other with shared `border-hard` lines and wrap to fit the width; no gaps, no tilt.
- Use names as the band members want them shown. Roles are instruments or parts: "Vocals", "Trombone", "Bass".
