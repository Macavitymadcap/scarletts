# Tape

A cut-out label: one to three uppercase words in the `tape` style on an `ink` or `scarlet` strip, tilted by `tilt-left` or `tilt-right`.

- Use it for kickers and status: "TONIGHT", "SOLD OUT", "NEW SINGLE". One or two per screen.
- Alternate `tilt` between neighbouring labels so they never line up.
- Never use it for sentences or anything a visitor must click.
