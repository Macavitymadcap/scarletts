# Reviews

Quotes about the band as flush tiles, like the line-up: the quote in bold `body` type between big `scarlet-ink` quote marks, and the source in `stamp` type below.

- Pass `reviews` as `{ content, source, citation? }`. With `citation`, the source links to it in `scarlet-ink`.
- Only real quotes, word for word, from someone with a name or a publication. Leave the section out until there is one.
- Tiles wrap to fit the width; no gaps, no tilt. Pair the section title with one `Tape` label, such as "Word on the street".
